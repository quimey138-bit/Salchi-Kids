# Salchi Kids — tienda

1. `npm install`
2. `npm run dev` y abrí http://localhost:3000

Dónde editar:
- `lib/config.js`: nombre y número de WhatsApp.
- `lib/products.js`: productos, precios, colores y tabla de talles (los datos actuales son de ejemplo).
- Fotos: poné los archivos en `public/productos/` y agregá `image: "/productos/archivo.jpg"` al producto.
